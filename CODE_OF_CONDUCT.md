# Code of conduct

Treat people with respect. Disagree with a claim and explain the evidence.
Accept corrections. Give contributors time to respond.
Keep reports concise and reproducible.

Harassment, threats, discrimination, personal attacks, and disclosure of private information are unacceptable.
This policy applies to issues, reviews, discussions, and other project spaces.
Maintainers can remove harmful content or restrict participation.
Repeated or serious violations can result in removal from the project.

Use GitHub's **Report content** menu on the affected content.
Select **Report to repository admins** when that option is available.
Otherwise, report the content to GitHub Support.
Include the location, relevant context, and any immediate concern.
Do not publish private details in a public issue.
A maintainer who is involved in a report must not decide its outcome alone.
