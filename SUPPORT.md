# Support

Read [installation](docs/INSTALLATION.md),
[upgrade](docs/UPGRADE.md), and
[troubleshooting](docs/TROUBLESHOOTING.md) first.
For a reproducible bug, use the bug form in the affected public repository.
For a documentation problem, use the documentation form.
Use the affected repository: `menot-you/n-memory`, `menot-you/n-spawn`, `menot-you/n-browser`, or `menot-you/plugin`.

Include the version, operating system, exact command, expected result, and redacted output.
State whether the issue occurs in a fresh disposable configuration.
Never attach a live database, provider key, private transcript, or rollback receipt.

Report security issues through [the private channel](SECURITY.md).
Report conduct concerns through [the code of conduct](CODE_OF_CONDUCT.md).
Support depends on maintainer availability. There is no response-time guarantee.
