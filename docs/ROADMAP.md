# Roadmap

Help make memory, native sessions, web evidence, and the working method inspectable.
These areas describe project direction. They do not promise dates.

| Area | Current boundary | Useful contribution |
| --- | --- | --- |
| Grounded recall | A result must keep its source and project scope | A synthetic regression for a missing or incorrect recall |
| Corrections | New decisions preserve the history they replace | A case that checks supersession and current context together |
| Native clients | Each host has its own events and trust controls | A real install or hook test for a supported client |
| Local processing | Model responses must pass the declared schema | A reproducible local-model compatibility report |
| Public evaluation | A claim needs exact inputs, metrics, and evidence | A replay case that another contributor can run |
| Native sessions | Admission and process custody remain enforced | A synthetic routing or restoration regression |
| Web evidence | Network and credential-origin checks remain enforced | A reproducible extraction or refusal case |
| Installation | Setup must preserve existing data and configuration | A clean-machine test or a clearer recovery step |

Start with [the contribution guide](../CONTRIBUTING.md).
Discuss a new integration before you expand the supported surface.
Keep examples synthetic and reports free of private records.
